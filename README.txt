WEBSITE ULANG TAHUN ZARA — 4 HALAMAN 💗

Halaman 1: hitung mundur menuju 15 Oktober 2026.
Halaman 2: menu Journey, Moment, Playlist dengan animasi hati.
Halaman 3: konten Journey (foto), Moment (ucapan), atau Playlist (video YouTube).
Halaman 4: Gift dan pesan penutup.

UPDATE WEBSITE YANG SUDAH ONLINE:
1. Buka repository Ultah-zara di GitHub.
2. Buka file index.html lalu tekan ikon pensil/Edit.
3. Pilih semua isi kode lama dan hapus, lalu tempel seluruh isi file index.html versi baru ini.
4. Tekan Commit changes untuk menyimpan.
5. Tunggu 1–5 menit, kemudian refresh website. Jika tampilan lama masih muncul, buka di tab samaran atau refresh lagi.

VIDEO YOUTUBE:
Pada halaman Playlist, tempel URL YouTube lengkap (contoh https://www.youtube.com/watch?v=VIDEO_ID) lalu tekan Putar video. Video ditampilkan langsung di halaman. Sebagian video tidak mengizinkan embed.

FOTO:
Pilihan foto di halaman Journey hanya preview di browser yang memilihnya. Agar pengunjung lain juga melihatnya, unggah foto ke folder assets lalu ubah HTML untuk menggunakan <img src="assets/namafoto.jpg" alt="Kenangan kita">.
